# 个人知识库 (Personal Knowledge Base)

这是一个基于云端同步和离线缓存双架构的现代化个人知识库。该项目致力于提供类似 Apple 备忘录 / Notion 的极致移动端阅读与写作体验，同时能够与本地的 Obsidian 文件夹进行无缝衔接。

## 🌟 核心特性 (Features)

*   **极致的移动端 UI/UX 设计**：
    *   **Bento Box (便当盒) 仪表盘**：分类展示置顶笔记、近期更新以及文件夹归档。
    *   **高斯模糊与系统级动效**：毛玻璃导航栏设计 (`backdrop-filter`)，结合微动画 (Micro-animations) 提供流畅操作手感。
    *   **深色/浅色模式无缝切换**：自动适配系统的主题偏好设置，或通过顶部按钮一键切换。
*   **企业级的 Markdown 渲染**：
    *   采用 `marked.js` 高性能解析 Markdown。
    *   集成了 `highlight.js` 与 Atom One Dark 主题，支持数百种语言的代码语法高亮。
    *   深度优化了文本排版：包含块引用、响应式表格、行内代码块等企业级知识库 UI 标准。
*   **零副作用的双链支持与 Frontmatter 解析**：
    *   完美兼容 Obsidian 的 `[[笔记名称]]` 语法，支持无缝页面内跳转！
    *   **非侵入式的置顶机制**：在网页端置顶笔记时，会自动往 Markdown 头部注入 `pinned: true`，不改变任何数据库表结构，与本地软件互不冲突。
*   **全功能的在线编辑 (支持离线优先架构)**：
    *   **新建笔记**：右下角悬浮按钮一键极速新建并进入编辑模式。
    *   **实时编辑**：网页内直接编辑 Markdown 源码，点击保存后使用 `Upsert` 机制极速同步到 Supabase 数据库。
    *   **绝对安全的 LocalStorage 本地持久化**：所有的保存和状态修改都会立即进入浏览器的本地缓存。**断网或者未连接数据库时，该网页依然可以作为独立的渐进式 Web 应用 (PWA) 正常运行，所有更改绝不丢失**！

## 🚀 核心架构与部署

1.  **Frontend (前端)**：
    *   采用纯原生的 HTML5 / CSS3 / ES6 构建，**零构建工具**，无需 Webpack / Vite，极致轻量，一秒极速冷启动。
    *   所有样式均为纯手工编写的原生 CSS 变量系统，易于二次扩展。
2.  **Backend (后端集成)**：
    *   通过 **Supabase REST API** 直接拉取和更新云端记录。
    *   利用自动生成的 `data.json` 提供零依赖的全量降级备用数据。
3.  **Local Sync (本地 Obsidian 同步)**：
    *   包含一个高效的 Python 同步脚本 (`sync_notes.py`)。
    *   支持递归扫描本地 iCloud / Obsidian Markdown 文件夹，并增量同步到 Supabase 平台。

## 🛠 本地开发与测试

该项目零构建环境依赖，想要进行二次开发只需：
1. `clone` 本仓库
2. 在本地开启一个 HTTP 服务即可（例如使用 Python：`python3 -m http.server 8000`）
3. 在浏览器打开 `http://localhost:8000`

> 详情请查阅项目自带的全功能点测试脚本：`test_flow.js` 以及附带的自动化全流程测试文档。
